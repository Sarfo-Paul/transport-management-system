# Database Schema for UG TransPass

## Overview
This document provides a comprehensive overview of the database schema utilized in the UG TransPass transport management system. The schema is designed to efficiently manage data related to bookings, routes, vehicles, drivers, and reports, ensuring seamless operation and data integrity.

## Tables

### 1. Bookings
- **Table Name**: `bookings`
- **Description**: Stores information about user bookings.
- **Columns**:
  - `id` (INT, Primary Key, Auto Increment)
  - `user_id` (INT, Foreign Key referencing `users.id`)
  - `route_id` (INT, Foreign Key referencing `routes.id`)
  - `travel_date` (DATE)
  - `status` (ENUM: 'confirmed', 'pending', 'cancelled', 'completed')
  - `created_at` (TIMESTAMP)
  - `updated_at` (TIMESTAMP)

### 2. Routes
- **Table Name**: `routes`
- **Description**: Contains details about transport routes.
- **Columns**:
  - `id` (INT, Primary Key, Auto Increment)
  - `name` (VARCHAR)
  - `start_location` (VARCHAR)
  - `end_location` (VARCHAR)
  - `status` (ENUM: 'active', 'inactive', 'under review')
  - `created_at` (TIMESTAMP)
  - `updated_at` (TIMESTAMP)

### 3. Route Schedules
- **Table Name**: `route_schedules`
- **Description**: Manages the schedules for each route.
- **Columns**:
  - `id` (INT, Primary Key, Auto Increment)
  - `route_id` (INT, Foreign Key referencing `routes.id`)
  - `departure_time` (TIME)
  - `arrival_time` (TIME)
  - `status` (ENUM: 'scheduled', 'in progress', 'completed', 'cancelled')
  - `created_at` (TIMESTAMP)
  - `updated_at` (TIMESTAMP)

### 4. Vehicles
- **Table Name**: `vehicles`
- **Description**: Information about the vehicles used in the transport system.
- **Columns**:
  - `id` (INT, Primary Key, Auto Increment)
  - `license_plate` (VARCHAR)
  - `model` (VARCHAR)
  - `capacity` (INT)
  - `status` (ENUM: 'active', 'maintenance', 'out of service')
  - `created_at` (TIMESTAMP)
  - `updated_at` (TIMESTAMP)

### 5. Drivers
- **Table Name**: `drivers`
- **Description**: Contains details about the drivers.
- **Columns**:
  - `id` (INT, Primary Key, Auto Increment)
  - `name` (VARCHAR)
  - `license_number` (VARCHAR)
  - `status` (ENUM: 'active', 'on leave', 'suspended', 'terminated')
  - `created_at` (TIMESTAMP)
  - `updated_at` (TIMESTAMP)

### 6. Reports
- **Table Name**: `reports`
- **Description**: Stores reports generated by users and drivers.
- **Columns**:
  - `id` (INT, Primary Key, Auto Increment)
  - `user_id` (INT, Foreign Key referencing `users.id`)
  - `driver_id` (INT, Foreign Key referencing `drivers.id`)
  - `content` (TEXT)
  - `status` (ENUM: 'pending', 'in progress', 'resolved', 'rejected')
  - `created_at` (TIMESTAMP)
  - `updated_at` (TIMESTAMP)

## Relationships
- **Bookings** are linked to **Users** and **Routes**.
- **Route Schedules** are associated with **Routes**.
- **Drivers** can be linked to **Reports**.

## Conclusion
This database schema is designed to support the functionalities of the UG TransPass transport management system, ensuring efficient data handling and integrity across various components of the application.
